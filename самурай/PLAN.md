# Самурай — план проекта

Интерактивная история о самурае: живая 3D-фигура в доспехе, семь добродетелей
Бусидо, анатомия доспеха, рождение катаны и тысяча лет эпох. Сайт статический и
работает без сборки: открыть `index.html` через любой локальный сервер.

---

## 1. Идея

**Одна фигура — тысяча лет истории.** Посетитель встречается с самураем лицом к
лицу. Воин следит взглядом за курсором, наносит удар по клику, а при прокрутке
камера обходит его доспех деталь за деталью. Текст короткий, как надпись на свитке.
Главное — ощущение присутствия.

Тон: сдержанный, уважительный, без «ниндзя-кича». Японская эстетика через
пустоту (*ма*), тушь, бумагу и один акцентный цвет.

## 3. Дизайн-система

**Цвета** (в начале `css/style.css`):

| Токен | Цвет | Смысл |
|-------|------|-------|
| `--washi` | `#efe8dc` | бумага васи, основной фон |
| `--sumi` | `#121011` | тушь суми, текст и тёмные секции |
| `--shu` | `#c73a2b` | киноварь сю — единственный яркий акцент |
| `--kin` | `#b8924a` | золото кин — детали, кромки, узоры |

**Шрифты:** Shippori Mincho B1 (иероглифы), Cormorant Garamond (заголовки,
кириллица), Manrope (текст).

**Приёмы:** вертикальное письмо (`writing-mode: vertical-rl`), контурные
иероглифы (`-webkit-text-stroke`), зерно бумаги поверх страницы, узор сэйгайха,
печать ханко, асимметричная композиция с большими пустотами.

## 4. Отслеживание курсора

- **Голова самурая** поворачивается к курсору. Угол считается от экранного
  положения головы, поэтому взгляд точен при любой композиции. Торс
  доворачивается на треть.
- **Глаза** разгораются, когда курсор рядом с лицом.
- **Тёплый фонарь** — точечный свет, который идёт за курсором и скользит бликом
  по лаку доспеха.
- **Камера** слегка смещается вслед за курсором (параллакс).
- **Ветер:** резкое движение мыши раздувает флаг сасимоно и сносит лепестки.
- **Курсор** — точка и кольцо с инерцией. Над ссылками кольцо растёт, над
  карточками появляется подпись 見 «Смотреть», над героем — 斬 «удар».
- **Карточки** наклоняются в 3D, подсветка идёт за курсором.
- **Магнитные кнопки** тянутся к курсору.
- Если курсор стоит без движения 4 секунды, взгляд начинает медленно блуждать.
  На телефоне фигура «осматривается» сама.

## 5. Анимации и технологии

| Что | Чем |
|-----|-----|
| 3D-сцена | Three.js r186: GLTFLoader, PMREM-окружение, ACES tone mapping, InstancedMesh для сакуры, `setViewOffset` для композиции |
| Таймлайны, скролл | GSAP 3.15 + ScrollTrigger (pin, scrub, горизонтальная дорожка) |
| Разбивка текста | SplitText с масками строк (`mask: 'lines'`) |
| Плавный скролл | Lenis |
| CSS нового поколения | `@property` для вращающейся кромки, scroll-driven animations (`animation-timeline: scroll()` / `view()`), маски по SVG, `backdrop-filter` |

## 6. 3D-модель

Модель собрана процедурно в `js/samurai-model.js`. Около 250 деталей из
примитивов: лакированные ламели, шнуровка одоси, кабуто с рёбрами-судзи, сикоро,
фукигаэси и золотой кувагатой, мэмпо с усами, содэ, кусадзури, хакама со
складками, сунэатэ, катана с изгибом сори, ножны, вакидзаси и флаг сасимоно.

Детали склеиваются по материалам в 76 мешей. Узлы названы для анимации:
`hips › torso › head / armL / armR › forearm › hand › katana`.

Экспорт в GLB (~830 КБ, ~36 тыс. треугольников):

```bash
cd самурай/tools
npm install
npm run build:model     # → assets/models/samurai.glb
```

Сайт загружает `samurai.glb`. Если файл недоступен, та же модель собирается
на лету из `samurai-model.js`.

## 7. Производительность и доступность

- Сцена не рисуется, когда её закрывают тёмные секции или вкладка скрыта.
- Адаптивное качество: при долгих кадрах снижается разрешение. На программном
  рендерере (SwiftShader, llvmpipe) сразу отключаются отражения и уменьшается
  число лепестков.
- Нет WebGL или CDN — показывается постер `samurai-poster.png`, контент
  остаётся доступен.
- `prefers-reduced-motion`: вступление пропускается, нет плавного скролла и
  декоративных анимаций.
- Семантичная разметка, `aria-label` на сцене, видимый фокус.
