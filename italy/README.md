# ITALIA — интерактивный путеводитель по Италии

Одностраничный сайт про Италию: карта 20 регионов, лента истории от нурагов до
Олимпиады-2026, разрез Колизея, кухня, разговорник с озвучкой, цифры и викторина.
Чистый HTML/CSS/JS — без сборки, зависимостей и фреймворков.

Открывается отдельно от корневого сайта студии: `/italy/`.

## Структура

```
index.html                    разметка всех секций + контуры регионов (SVG-пути)
assets/css/style.css          стили, адаптив, анимации появления
assets/js/data.js             всё содержимое: регионы, история, Колизей, кухня,
                              разговорник, викторина, практика — правится без вёрстки
assets/js/colosseum.js        Колизей: процедурный фасад на первом экране + разрез
assets/js/map.js              интерактивная карта регионов
assets/js/main.js             прелоадер, курсор, появление, счётчики, лента истории,
                              разговорник, викторина, пыль на canvas
assets/img/favicon.svg
```

## Запуск

```bash
python3 -m http.server 8000
# http://localhost:8000/italy/
```

## Что интерактивного

| Блок | Что делает |
|------|------------|
| Первый экран | Колизей собирается из 80 арок процедурно: перспектива по эллипсу, ступенчатый обрыв внешнего кольца, внутренняя стена за ним. Ползунок меняет время суток — небо, солнце/луна, цвет травертина, тени и ночная подсветка арок. Курсор двигает здание параллаксом, наведение подсвечивает арку |
| Карта регионов | 20 кликабельных контуров, карточка региона со столицей, цифрами, блюдом и вином; фильтр по частям страны; заливка по населению, плотности или площади; подписи городов и вулканов |
| Лента истории | 22 события с горизонтальной прокруткой колесом, свайпом и стрелками, полоса прогресса |
| Колизей | Разрез с восемью слоями: веларий, аттик, ордера, трибуны, арена, гипогей, входы, травертин. Точки на чертеже и список синхронизированы |
| Кухня | Формы пасты с нарисованными кодом значками, кофейные правила, правила за столом |
| Разговорник | 16 фраз с транскрипцией; кнопка произносит фразу через Web Speech API (голос it-IT) |
| Викторина | 10 вопросов с мгновенным разбором и итогом |

Всё рисуется кодом — SVG и canvas. Фотографий в проекте нет, поэтому нет и вопросов
с правами на изображения.

## Данные

Цифры актуальны на сентябрь 2026 года:

* население, коммуны, рождаемость, продолжительность жизни — [ISTAT](https://www.istat.it/en/);
* вино (47,4 млн гл, 2025) — [OIV](https://www.oiv.int/);
* 62 объекта Всемирного наследия и кухня в списке нематериального наследия — [UNESCO](https://whc.unesco.org/en/statesparties/it);
* посещаемость Колизея — [Parco archeologico del Colosseo](https://colosseo.it/en/);
* высота Этны (3403 м, замер 2024) — [INGV](https://www.ingv.it/);
* ВВП — [IMF WEO](https://www.imf.org/en/Publications/WEO).

Число объектов ЮНЕСКО по регионам в карточках приблизительное: часть памятников
серийные и расположены сразу в нескольких регионах.

## Лицензии

Контуры регионов взяты из пакета [@svg-maps/italy](https://github.com/VictorCazanave/svg-maps)
(Victor Cazanave, CC BY 4.0) — ссылка на источник стоит в подвале сайта. Остальная
графика нарисована для этого проекта.

## Правка содержимого

Тексты, цифры и списки лежат в `assets/js/data.js` — одним объектом на секцию.
Добавить регион, событие в ленту, фразу или вопрос викторины можно, не трогая
разметку: блоки перерисовываются из данных при загрузке.
