# Mainframe® — портфолио

React-приложение портфолио: главная с интерактивным героем и фоновым видео,
которое скрабится мышью, и отдельная страница работ со сценой на Three.js.

Основной сайт студии («На твоё усмотрение») лежит в корне репозитория и
остаётся статическим — это приложение живёт рядом и ни на что там не влияет.

## Стек

Vite · React 19 · TypeScript · Tailwind CSS v4 · Motion (`motion/react`) ·
lucide-react · react-router-dom · three / @react-three/fiber / drei.

## Запуск

```bash
cd app
npm install
npm run dev      # http://localhost:5173
npm run build    # сборка в dist/
npm run preview  # проверка собранного билда
```

## Маршруты

`HashRouter`, а не `BrowserRouter`: сборка статическая и кладётся в любую папку
любого хостинга, где нет фолбэка на `index.html` — при прямом заходе на `/work`
сервер вернул бы 404. Адреса выглядят как `/#/` и `/#/work`.

Хэш занят роутером, поэтому якоря вида `/work#studio` не работают: ссылки
«Studio», «Openings» и «Shop» передают идентификатор секции состоянием
маршрута, а страница работ прокручивается к ней в эффекте.

## Фоновое видео

Ролик не проигрывается сам по себе на десктопе — кадр привязан к курсору.
Движение мыши по горизонтали пересчитывается в дельту времени:
`(delta / window.innerWidth) * 0.8 * duration`, то есть полный проход по экрану
прокручивает 80% ролика. Значение зажимается в `[0, duration]`, перемотка
выполняется через `currentTime`, а следующий кадр ставится в очередь по
событию `seeked` — иначе браузер копит запросы и картинка дёргается.

Ниже 1024px скраба нет (курсора тоже), поэтому там включается обычное
зацикленное воспроизведение: `muted` + `playsInline` позволяют автозапуск
на iOS.

### Запасной фон

Ролик лежит на внешнем CDN и может не открыться — из-за сети, блокировщика
или корпоративного прокси. Раньше на его месте оставалось белое пятно в пол-экрана.
Теперь по `error` или по таймауту в 4 секунды (`readyState < 2`) включается
собственная графика: цветная подложка `LiquidCanvas` и поверх неё `WaveField` —
сетка в перспективе, по которой бежит волна и которая ведёт за курсором.

Оба полотна следят за своим размером через `ResizeObserver`: высота контейнера
задана `aspect-ratio` и на момент монтирования равна нулю, а без наблюдателя
canvas оставался размером 1×1 и растягивался в серое пятно.

Считается всё в 2D-контексте линиями, без единой зависимости и без WebGL:
на светлом фоне линии читаются как графика, а не как размытое пятно, и стоят
дешевле любого блюра. Вне экрана цикл простаивает, при `prefers-reduced-motion`
рисуется один кадр.

## Ассеты

Растровых картинок в проекте нет. Превью проектов, аватары команды и обложки
товаров рисует `ProjectThumb` — SVG с четырьмя типами композиции (кольца,
диагональные полосы, модульная сетка, волна). Тип и параметры детерминированы,
их задаёт `seed`, поэтому соседние карточки не повторяются. Каждое превью —
сотни байт и ни одного сетевого запроса.

Зерно поверх фона — тоже SVG, инлайном в `data:`-URI: оно убирает полосатость
градиента на больших площадях.

## Слои и z-index

Три фиксированных слоя, порядок важен:

| Слой | z-index |
|------|---------|
| фоновое видео | `z-0` (на десктопе `absolute inset-0`) |
| контент — герой, текст, пилюли | `z-10` |
| мобильное меню | `z-20` |
| шапка | `z-30` |

Шапка обязана быть выше меню: кнопка закрытия лежит внутри неё, и на более
низком значении она оказывается под оверлеем и перестаёт нажиматься —
собственный `z-index` кнопке не помогает, он считается внутри контекста
наложения шапки.

## Шапка

Прозрачная только на самом верху страницы. Ниже под неё заезжает контент, и
текст накладывался на логотип и ссылки — поэтому после `scrollY > 8`
появляется подложка `bg-white/85` с размытием. На первом экране, где справа
идёт видео, шапка остаётся прозрачной, как и задумано.

## Сцена на Three.js

Узел (`torusKnotGeometry`) с `MeshDistortMaterial` и пять икосаэдров на орбите.
Композиция смещена вправо (`position={[1.9, 0.2, 0]}`), слева поверх неё лежит
градиентная шторка — иначе заголовок читается поверх тёмной геометрии плохо.

Окружение собрано из `Lightformer`'ов, а не из `Environment preset`: пресет
тянет HDR-карту с внешнего CDN — лишний запрос и белая сцена там, где CDN
недоступен.

При `prefers-reduced-motion: reduce` вращение и дисторшн выключаются, а
рендер-цикл переводится в режим `demand` — сцена рисуется одним кадром.

## Уважение к prefers-reduced-motion

`MotionConfig reducedMotion="user"` глушит анимации Motion целиком. Сверх
этого: печатная машинка сразу показывает готовую строку, курсор не мигает,
3D-сцена не вращается и рендерится одним кадром.

## Вес

Three.js тянет около мегабайта, поэтому страница работ подключена через
`React.lazy`: на главной этот код не загружается.

| Чанк | gzip |
|------|------|
| главная | ~123 кБ |
| страница работ (по требованию) | ~263 кБ |
