# Mainframe® — портфолио

React-приложение портфолио: главная с интерактивным героем и фоновым видео,
которое скрабится мышью, и отдельная страница работ со сценой на Three.js.

Основной сайт студии («На твоё усмотрение») лежит в корне репозитория и
остаётся статическим — это приложение живёт рядом и ни на что там не влияет.

## Стек

Vite · React 19 · TypeScript · Tailwind CSS v4 · Motion (`motion/react`) ·
lucide-react · react-router-dom · three / @react-three/fiber / drei.

## Запуск

```bash
cd app
npm install
npm run dev      # http://localhost:5173
npm run build    # сборка в dist/
npm run preview  # проверка собранного билда
```

## Фоновое видео

Ролик не проигрывается сам по себе на десктопе — кадр привязан к курсору.
Движение мыши по горизонтали пересчитывается в дельту времени:
`(delta / window.innerWidth) * 0.8 * duration`, то есть полный проход по экрану
прокручивает 80% ролика. Значение зажимается в `[0, duration]`, перемотка
выполняется через `currentTime`, а следующий кадр ставится в очередь по
событию `seeked` — иначе браузер копит запросы и картинка дёргается.

Ниже 1024px скраба нет (курсора тоже), поэтому там включается обычное
зацикленное воспроизведение: `muted` + `playsInline` позволяют автозапуск
на iOS.

## Слои и z-index

Три фиксированных слоя, порядок важен:

| Слой | z-index |
|------|---------|
| фоновое видео | `z-0` (на десктопе `absolute inset-0`) |
| контент — герой, текст, пилюли | `z-10` |
| мобильное меню | `z-20` |
| шапка | `z-30` |

Шапка обязана быть выше меню: кнопка закрытия лежит внутри неё, и на более
низком значении она оказывается под оверлеем и перестаёт нажиматься —
собственный `z-index` кнопке не помогает, он считается внутри контекста
наложения шапки.

## Сцена на Three.js

Узел (`torusKnotGeometry`) с `MeshDistortMaterial` и пять икосаэдров на орбите.
Композиция смещена вправо (`position={[1.9, 0.2, 0]}`), слева поверх неё лежит
градиентная шторка — иначе заголовок читается поверх тёмной геометрии плохо.

Окружение собрано из `Lightformer`'ов, а не из `Environment preset`: пресет
тянет HDR-карту с внешнего CDN — лишний запрос и белая сцена там, где CDN
недоступен.

При `prefers-reduced-motion: reduce` вращение и дисторшн выключаются, а
рендер-цикл переводится в режим `demand` — сцена рисуется одним кадром.

## Вес

Three.js тянет около мегабайта, поэтому страница работ подключена через
`React.lazy`: на главной этот код не загружается.

| Чанк | gzip |
|------|------|
| главная | ~128 кБ |
| страница работ (по требованию) | ~261 кБ |
