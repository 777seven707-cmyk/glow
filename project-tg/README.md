# project tg — школа курсов по вайбкодингу и нейросетям

Полный план создания линейки онлайн-курсов: от идеи до запуска и масштабирования, расписанный по неделям.

> **Допущение:** «tg» = Telegram. Курсы выдаются через закрытый Telegram-канал/чат + бот-выдачу доступа, а вся доставка контента и оплата строятся вокруг Telegram. Если задумано иначе — меняется только `01-strategy.md` (раздел «Платформа»), содержание курсов остаётся прежним.

## Важно про инструменты

Нейросети и сервисы меняются каждые несколько месяцев. В программах указаны **классы инструментов и примеры**, а не жёсткая привязка к версиям. Перед записью каждого модуля — проверка актуальности (чек-лист в `02-production.md`).
