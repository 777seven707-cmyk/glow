# Производство курсов

## 1. Шаблон урока
Каждый урок содержит один и тот же набор:

1. **Цель** — одна фраза: «после урока ты сможешь…»
2. **Видео** 8–15 минут: хук (30 сек) → объяснение → показ на экране → итог
3. **Конспект** — ключевые шаги и промпты, которые можно скопировать
4. **Практика** — задание на 15–40 минут с чётким результатом
5. **Проверка** — как ученик поймёт, что всё получилось (чек-лист)
6. **Частые ошибки** — 3–5 пунктов

### Структура файлов на урок
```
course-XX/
  week-N/
    lesson-N.M/
      script.md        # сценарий
      slides/          # материалы к видео
      raw/             # исходная запись (в облаке, не в репозитории)
      final/           # финальный ролик (в облаке)
      notes.md         # конспект для учеников
      homework.md      # задание и критерии
```

## 2. Конвейер производства (на один урок)

| Шаг | Что делаем | Время |
|---|---|---|
| 1 | Сценарий и тезисы, проверка актуальности инструментов | 30–60 мин |
| 2 | Подготовка экрана: чистый рабочий стол, тестовые аккаунты | 15 мин |
| 3 | Запись (экран + голос, при необходимости камера) | 30–60 мин |
| 4 | Монтаж: нарезка, субтитры, звук, акценты | 45–90 мин |
| 5 | Конспект и ДЗ | 30 мин |
| 6 | QA и загрузка | 15 мин |

Ориентир: **один урок на 10 минут ≈ 3–4 часа работы целиком**. Курс из 25 уроков ≈ 100 часов, закладывать 2–4 недели с буфером.

## 3. Стек инструментов (классы, проверять актуальность)

| Задача | Класс инструмента |
|---|---|
| Запись экрана | Экранный рекордер с записью голоса |
| Монтаж | Настольный или облачный видеоредактор с авто-субтитрами |
| Звук | Микрофон USB/XLR, шумоподавление на ИИ |
| Хранение видео | Закрытый видеохостинг / облако |
| Материалы | Документы (Notion/Docs), GitHub для шаблонов |
| Бот и платежи | Telegram-бот + платёжный провайдер |
| ИИ для записи демо | Подписки на актуальные нейросети (текст, код, картинки, видео, голос) |
| Кураторская работа | Таблица ДЗ, шаблоны обратной связи |

## 4. Чек-лист перед записью модуля
- [ ] Проверить, что показываемые инструменты работают и не изменили интерфейс
- [ ] Проверить цены, лимиты, доступность в регионе учеников
- [ ] Подготовить запасной вариант для каждого платного сервиса (бесплатная альтернатива)
- [ ] Скрыть личные данные, ключи, уведомления
- [ ] Проверить права на музыку, шрифты, изображения в уроке

## 5. QA готового урока
- [ ] Звук чистый, нет провалов громкости
- [ ] Всё, что показано на экране, читаемо на телефоне
- [ ] Субтитры без ошибок
- [ ] Конспект совпадает с видео
- [ ] Практика выполнима за указанное время (проверил бета-тестер)
- [ ] Нет утёкших ключей/паролей в кадре

## 6. Обновление курсов
- Раз в 2 недели: обзор новостей в мире нейросетей (30 мин)
- Раз в месяц: «обновление» — короткие видео по изменившимся инструментам
- Раз в квартал: ревизия программы, замена устаревших модулей
- В каждом курсе — модуль «Что изменилось» в закреплённом канале

## 7. Работа куратора
- Ответ в чате в течение 24 часов (в будни)
- Проверка ДЗ: 48 часов, по шаблону — что хорошо, что улучшить, следующий шаг
- Еженедельный эфир: разбор типичных ошибок и лучших работ
- Мотивация: рейтинг «работы недели», напоминания в боте о дедлайнах
- Ученики, не заходящие 5 дней, получают личное сообщение

## 8. Обратная связь и улучшение
- Анкета после каждой недели (3 вопроса: понятно / сложно / чего не хватило)
- Опрос по завершении: NPS и отзыв
- Каждые 2 недели — правки по самым частым замечаниям
