# Стратегия

## 1. Аудитория

| Сегмент | Портрет | Боль | Главный курс |
|---|---|---|---|
| Новички-«гуманитарии» | 22–45 лет, без кода, хотят использовать ИИ в работе | «Не понимаю, с чего начать» | 0 |
| Предприниматели / эксперты | Свой бизнес, блог, услуги | Нет сайта, нет контента, нет бюджета на команду | 0 → 1 → 3 |
| Контент-мейкеры / блогеры | Reels, Shorts, TikTok | Долго монтировать, нет идей, нет «лица» | 2, 3, 5 |
| Фрилансеры / студенты | Ищут доп. доход | Нужна востребованная навыковая база | 0 → 1 / 2 |
| Дизайнеры / фотографы | Уже в профессии | Конкуренция с ИИ, хочет ускориться | 4, 5 |

## 2. Позиционирование
**«Практика с первого урока, результат в конце каждой недели».**
- Не «теория про ИИ», а готовый результат: сайт, ролик, фотосессия, аватар
- Без программирования с нуля — через вайбкодинг (работа с ИИ-агентом)
- Каждый курс заканчивается проектом для портфолио

## 3. Платформа (Telegram)
- **Публичный канал** — контент, кейсы, прогрев
- **Закрытый канал курса** — уроки (видео + конспект)
- **Закрытый чат потока** — вопросы, ДЗ, куратор
- **Бот** — оплата, выдача инвайт-ссылок, напоминания, промокоды, статистика
- **Хранение видео** — облако/видеохостинг с закрытым доступом (Telegram ограничивает размер файлов; видео лучше хостить отдельно и давать ссылку)
- **Материалы** — Notion/Google Docs, репозитории на GitHub

## 4. Формат обучения
- Недельный цикл: **понедельник** — новые уроки; **вт–пт** — практика и вопросы; **пятница** — сдача ДЗ; **воскресенье** — разбор/эфир
- Урок = видео 8–15 мин + конспект + шаблон/промпты + практическое задание
- Обратная связь: проверка ДЗ куратором, еженедельный эфир Q&A
