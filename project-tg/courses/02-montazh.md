# Курс 2. Монтаж видео с ИИ

**Длительность:** 5 недель · **Нагрузка:** 5–6 ч/неделя · **Пререквизит:** Курс 0
**Результат:** ученик монтирует ролики (Reels/Shorts/YouTube/продающие) в 3–5 раз быстрее, автоматизируя рутину нейросетями, и имеет портфолио из 5 роликов.

## Что умеет выпускник
- Понимать язык монтажа: план, ритм, склейки, композиция
- Автоматизировать нарезку, субтитры, чистку звука, цветокоррекцию
- Делать вертикальные, горизонтальные и квадратные версии из одного исходника
- Использовать ИИ для сценария, озвучки, музыки, титров
- Сдавать заказы: тайминг, правки, экспорт, ценообразование

## Неделя 1. Основы монтажа
**Цель:** понимать, как устроен ролик, и уверенно работать в редакторе.

| Урок | Тема | Практика |
|---|---|---|
| 1.1 | Как устроено видео: кадры, разрешение, кодеки, форматы, битрейт | Настроить проект под платформы |
| 1.2 | Выбор редактора: настольный, мобильный, облачный; интерфейс | Установка и первый проект |
| 1.3 | Язык монтажа: планы, склейки, ритм, J/L-cut | Разбор роликов по монтажным склейкам |
| 1.4 | Рабочий процесс: импорт, черновая сборка, тонкая настройка, экспорт | Смонтировать 30-секундный ролик |
| 1.5 | Хранение, именование, резервные копии | Организовать проект |

**ДЗ:** ролик 30–45 секунд из подготовленных материалов.

## Неделя 2. Нейросети для рутины: нарезка, субтитры, звук
**Цель:** ускорить черновой монтаж.

| Урок | Тема | Практика |
|---|---|---|
| 2.1 | Автоматическая транскрибация и субтитры; правка и стилизация | Субтитры в брендовом стиле |
| 2.2 | Удаление пауз и «эээ», нарезка по смыслу | Нарезать длинное видео на 5 клипов |
| 2.3 | Улучшение звука: шумоподавление, эквализация, нормализация громкости | До/после на плохой записи |
| 2.4 | ИИ-озвучка и перевод: синтез голоса, дубляж, субтитры на другие языки | Озвучить ролик на 2 языках |
| 2.5 | Музыка и звуковые эффекты: генерация, лицензии | Подобрать/сгенерировать трек |

**ДЗ:** длинное видео → 3 коротких ролика с субтитрами и чистым звуком.

## Неделя 3. Картинка: цвет, стабилизация, эффекты
**Цель:** привести картинку к профессиональному виду.

| Урок | Тема | Практика |
|---|---|---|
| 3.1 | Цветокоррекция и цветокор: баланс белого, экспозиция, LUT | Выровнять 3 разных клипа |
| 3.2 | Автоматизация цвета и улучшение качества: апскейл, шумодав, стабилизация | Улучшить старую съёмку |
| 3.3 | Удаление фона и объектов, маски, отслеживание | Заменить фон |
| 3.4 | Переходы, анимация текста, титры — умеренно | Шаблон титров под бренд |
| 3.5 | Ускорение/замедление, интерполяция кадров, эффект «кино» | Сцена с плавным замедлением |

**ДЗ:** ролик с цветокором, титрами и одной «эффектной» сценой.

## Неделя 4. Форматы и платформы
**Цель:** один исходник → много версий под разные площадки.

| Урок | Тема | Практика |
|---|---|---|
| 4.1 | Вертикальный, квадратный, горизонтальный: автокадрирование под формат | Три версии одного ролика |
| 4.2 | Удержание внимания: хук в первые 3 секунды, темп, структура | Переделать начало 3 роликов |
| 4.3 | Reels/Shorts/TikTok/YouTube/Telegram: требования и алгоритмы | Шпаргалка по площадкам |
| 4.4 | Шаблоны и пресеты: ускоряем повторяющиеся задачи | Собрать личный пресет-пак |
| 4.5 | Обложки, превью, названия, описания с ИИ | Превью для 3 роликов |

**ДЗ:** пакет из 3 роликов в трёх форматах с обложками.

## Неделя 5. Проект и профессия
**Цель:** портфолио и умение брать заказы.

| Урок | Тема | Практика |
|---|---|---|
| 5.1 | Ведение заказа: ТЗ, референсы, этапы, правки, договор | Шаблон брифа |
| 5.2 | Цены и пакеты услуг, портфолио, где искать клиентов | Прайс и оффер |
| 5.3 | Свой конвейер: чек-лист монтажа на каждый ролик | Личная система |
| 5.4 | Разбор финальных работ | Обратная связь |

**Финальный проект:** серия из 3–5 роликов по одной теме/бренду (разные форматы), с субтитрами, звуком и обложками.

### Критерии зачёта
- Звук чистый, громкость выровнена, субтитры без ошибок
- Ролики оптимизированы под форматы, в кадре нет обрезанных элементов
- Есть работающие пресеты/шаблоны
- Использована лицензионно чистая музыка/графика

### Материалы
Пресеты титров, LUT-пак, шпаргалки по площадкам, шаблон брифа и договора, чек-лист монтажа.
