# Маркетинг и запуск

## 1. Воронка
```
Контент (Telegram, Reels/Shorts, YouTube) → Подписка на канал → Бесплатный продукт (мини-курс/чек-лист)
→ Прогрев (серия постов, кейсы, эфир) → Заявка/оплата в боте → Онбординг → Обучение → Апсейл следующего курса
```

## 2. Лид-магниты (бесплатные входные продукты)
- Мини-урок «Свой первый сайт за 30 минут» → ведёт в Курс 1
- Пак промптов для фото → Курс 4
- Шаблон «Как нарезать длинное видео за 10 минут» → Курс 2
- «Твой аватар за вечер» (пошаговый гайд) → Курс 5
- Чек-лист «10 ошибок новичка в вайбкодинге» → Курс 0

## 3. Публичный контент
| Рубрика | Формат | Частота |
|---|---|---|
| «Сделано нейросетью» — до/после, процесс | Reels/Shorts + пост | 3/нед |
| «Разбор инструмента» — 60 сек обзор | Видео | 2/нед |
| «Кейс ученика» | Пост + видео | 1/нед |
| «Промпт дня» | Пост | ежедневно |
| Прямой эфир «Собираем проект с нуля» | Эфир | 1/2 нед |

Правило: **каждый пост показывает результат**, а не рассуждает об ИИ.

## 4. План по неделям (для запуска Курса 0; шаблон для остальных)

### За 4 недели до старта
- Запуск публичного канала, 10–12 постов, вовлечение
- Интервью с аудиторией, сбор вопросов и возражений

### За 3 недели
- Лид-магнит + бот выдачи
- Первые тестовые рекламные закупки (микро-блогеры, каналы по теме)

### За 2 недели
- Открытие списка ожидания со скидкой раннего доступа
- Серия «кейсов» (бета-тестеры)

### За 1 неделю
- 2 бесплатных эфира: «Как работать с ИИ» и «Соберём мини-проект вживую»
- Ответы на возражения: «сложно», «не смогу», «устареет», «дорого»

### Неделя открытия (5–7 дней)
- День 1: открытие продаж, цена раннего доступа
- Дни 2–4: отзывы, разбор программы, ответы на вопросы
- День 5: дедлайн скидки, напоминания в боте
- День 6–7: закрытие набора, последний шанс

### После старта
- Приветствие и онбординг: карта курса, правила, знакомство в чате
- Первая победа в первые 48 часов (маленькое ДЗ)

## 5. Офферы и скидки
- Ранний доступ: −30% первые 5–7 дней
- Пакеты из нескольких курсов: −20–35%
- Скидка выпускника на следующий курс: −20%
- Партнёрка: 10–20% за приведённого ученика
- Гарантия: возврат в течение 7 дней, если пройдено ≤ 20% программы (условия в оферте)

## 6. Работа с возражениями
| Возражение | Ответ |
|---|---|
| «Я не умею программировать» | Курс начинается с нуля, кода вручную не пишем |
| «ИИ быстро меняется, курс устареет» | Обновления включены, обучаем принципам, а не кнопкам |
| «Бесплатно есть на YouTube» | Система, шаблоны, проверка ДЗ и результат к концу недели |
| «Нет времени» | 4–6 часов в неделю, уроки по 10 минут |
| «Дорого» | Рассрочка, пакеты, сравнение с ценой заказа сайта/ролика |

## 7. Метрики и отчёт (еженедельно)
- Охват, подписчики, стоимость подписчика
- Переходы в бота, заявки, оплаты, конверсии по шагам
- Доходимость курса, отзывы, возвраты
- Выручка, расходы, окупаемость (ROMI)
- Решение на неделю: что усиливаем, что отключаем

## 8. Каналы привлечения
1. **Органика:** Telegram-канал, Reels/Shorts, YouTube, комментинг в тематических сообществах
2. **Партнёрства:** блогеры и эксперты по ИИ/маркетингу, совместные эфиры
3. **Реклама:** закупы в Telegram-каналах, таргет — после отработки органикой
4. **Рефералы:** бонусы ученикам за приглашённых
5. **Кейсы выпускников:** публичные сайты, ролики и фото учеников
