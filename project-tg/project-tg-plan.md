# Общий план проекта по неделям (20 недель)

Цель: за 20 недель пройти путь от идеи до работающей школы с 6 курсами, первыми учениками и отлаженной воронкой.

Принцип: **не записывать всё сразу**. Сначала MVP-курс (основа) → продажа → запись следующих курсов на деньги и обратную связь первой когорты.

Условные роли (может быть один человек): **Автор** (программа, уроки), **Продюсер** (запись, монтаж), **Маркетолог**, **Куратор** (проверка ДЗ, чат).

## Контрольные точки (go / no-go)

| Неделя | Проверка | Условие продолжения |
|---|---|---|
| 3 | Технический конвейер работает | Оплата → доступ проходит без ручных действий |
| 7 | Бета-тест | ≥ 70% бета-тестеров дошли до финального проекта |
| 8 | Первый запуск | ≥ 10 платных учеников (иначе — доработка оффера, не запись новых курсов) |
| 14 | Второй запуск | Возвраты < 10%, NPS ≥ 40 |
| 20 | Линейка | Окупаемость производства ≥ 70% |

## Риски по срокам
- Запись занимает в 2–3 раза больше времени, чем кажется → закладывать буфер 20%
- Инструменты обновятся до выхода курса → «быстрый» модуль-обновление в конце каждого курса
- Узкое место — куратор: при > 30 учеников нанимать помощника

# Стратегия

## 1. Аудитория

| Сегмент | Портрет | Боль | Главный курс |
|---|---|---|---|
| Новички-«гуманитарии» | 22–45 лет, без кода, хотят использовать ИИ в работе | «Не понимаю, с чего начать» | 0 |
| Предприниматели / эксперты | Свой бизнес, блог, услуги | Нет сайта, нет контента, нет бюджета на команду | 0 → 1 → 3 |
| Контент-мейкеры / блогеры | Reels, Shorts, TikTok | Долго монтировать, нет идей, нет «лица» | 2, 3, 5 |
| Фрилансеры / студенты | Ищут доп. доход | Нужна востребованная навыковая база | 0 → 1 / 2 |
| Дизайнеры / фотографы | Уже в профессии | Конкуренция с ИИ, хочет ускориться | 4, 5 |

## 2. Позиционирование
**«Практика с первого урока, результат в конце каждой недели».**
- Не «теория про ИИ», а готовый результат: сайт, ролик, фотосессия, аватар
- Без программирования с нуля — через вайбкодинг (работа с ИИ-агентом)
- Каждый курс заканчивается проектом для портфолио

## 3. Платформа (Telegram)
- **Публичный канал** — контент, кейсы, прогрев
- **Закрытый канал курса** — уроки (видео + конспект)
- **Закрытый чат потока** — вопросы, ДЗ, куратор
- **Бот** — оплата, выдача инвайт-ссылок, напоминания, промокоды, статистика
- **Хранение видео** — облако/видеохостинг с закрытым доступом (Telegram ограничивает размер файлов; видео лучше хостить отдельно и давать ссылку)
- **Материалы** — Notion/Google Docs, репозитории на GitHub

## 4. Формат обучения
- Недельный цикл: **понедельник** — новые уроки; **вт–пт** — практика и вопросы; **пятница** — сдача ДЗ; **воскресенье** — разбор/эфир
- Урок = видео 8–15 мин + конспект + шаблон/промпты + практическое задание
- Обратная связь: проверка ДЗ куратором, еженедельный эфир Q&A

## 5. Монетизация и цены (ориентир, проверить интервью и тестом)

| Продукт | Ориентир, ₽ | Комментарий |
|---|---|---|
| Курс 0 «Основа» | 4 900–7 900 | Входной продукт |
| Курс 4 «Фото» | 3 900–6 900 | Быстрый результат, низкий порог |
| Курс 1 «Сайты» | 9 900–14 900 | Высокая воспринимаемая ценность |
| Курс 2 «Монтаж» | 7 900–11 900 | |
| Курс 3 «Генерация видео» | 9 900–14 900 | |
| Курс 5 «Аватары» | 6 900–9 900 | |
| Пакеты | скидка 20–35% | Апсейл после курса 0 |
| Клуб (подписка) | 490–990 / мес | Обновления, чат, эфиры |
| Тариф «С куратором» | +50% к цене | Проверка ДЗ и обратная связь |

Дополнительно: партнёрская программа для выпускников (10–20%), корпоративное обучение, шаблоны/промпт-паки как отдельные цифровые продукты.

## 6. Метрики

| Этап | Метрика | Цель |
|---|---|---|
| Привлечение | Стоимость подписчика | ≤ 60 ₽ |
| Прогрев | Конверсия подписчик → заявка | 3–5% |
| Продажа | Конверсия заявка → оплата | 15–25% |
| Обучение | Доходимость до финального проекта | ≥ 50% |
| Качество | NPS | ≥ 40 |
| Финансы | Возвраты | < 10% |
| Рост | Доля повторных покупок | ≥ 25% |

## 7. Бюджет запуска (ориентировочно, ₽)

| Статья | Сумма |
|---|---|
| Оборудование (микрофон, свет, при необходимости веб-камера) | 15 000–40 000 |
| Подписки на ИИ-сервисы для записи и тестов (в месяц) | 8 000–25 000 |
| Видеохостинг, домен, бот, CRM | 3 000–8 000 / мес |
| Платёжная система (комиссия) | 3–7% от оборота |
| Реклама (тест, старт) | 30 000–100 000 |
| Помощник-куратор | 15 000–40 000 / мес |
| Юридика (оферта, политика) | 10 000–20 000 |

Суммы условные — уточнить по актуальным ценам перед стартом.

## 8. Рекомендуемые связки для учеников

# Курс 0. Основа: вайбкодинг и нейросети с нуля

**Длительность:** 4 недели · **Нагрузка:** 4–6 ч/неделя · **Уровень:** с нуля
**Результат:** ученик уверенно пишет промпты, понимает, как работают нейросети, и собирает и публикует свой первый рабочий мини-проект с помощью ИИ-агента без ручного программирования.

## Для кого
Новички без опыта. Обязательная база для всех остальных курсов.

## Что умеет выпускник
- Объяснить простым языком, что такое LLM, токены, контекст, галлюцинации
- Писать структурные промпты и итеративно улучшать результат
- Подбирать нейросеть под задачу (текст, код, картинки, видео, звук)
- Собрать и запустить простой проект «вайбкодингом»
- Использовать Git/GitHub на базовом уровне и опубликовать результат
- Безопасно работать с ИИ (данные, ключи, авторские права)

---

## Неделя 1. Как думают нейросети и как с ними говорить

**Цель недели:** понять принципы и научиться получать нужный ответ с первой–третьей попытки.

| Урок | Тема | Практика |
|---|---|---|
| 1.1 | Карта нейросетей: текст, изображения, видео, звук, агенты. Что умеет и не умеет ИИ | Завести аккаунты, пройти чек-лист безопасности |
| 1.2 | Как работает LLM: токены, контекст, температура, галлюцинации | 3 эксперимента с одним вопросом и разными настройками |
| 1.3 | Анатомия промпта: роль, контекст, задача, формат, ограничения, примеры | Переписать 5 слабых промптов в сильные |
| 1.4 | Итерации и уточнения; цепочки промптов; «попроси ИИ задать вопросы» | Довести текст/задачу до результата за 3 итерации |
| 1.5 | Проверка фактов и защита от галлюцинаций | Найти 3 ошибки в ответе ИИ |
| 1.6 | Личная база промптов и «системные инструкции» | Собрать свою библиотеку из 10 промптов |

**ДЗ недели 1:** решить 3 реальные рабочие/жизненные задачи через ИИ и приложить промпты + результат.

## Неделя 2. Вайбкодинг: первый проект за вечер

**Цель недели:** собрать работающее приложение без написания кода вручную.

| Урок | Тема | Практика |
|---|---|---|

| 2.4 | Первый проект: трекер привычек / калькулятор / визитка (на выбор) | Собрать проект по шагам |

## Неделя 3. Проект, Git и данные

**Цель недели:** довести проект до состояния «показать людям» и научиться сохранять версии.

| Урок | Тема | Практика |
|---|---|---|
| 3.1 | Git и GitHub для нефанатов: коммиты, ветки, откат | Создать репозиторий, сделать 5 коммитов, откатиться |

**ДЗ недели 3:** проект в GitHub с README и историей коммитов.

## Неделя 4. Публикация и финальный проект

**Цель недели:** выпустить проект в интернет и подготовить кейс в портфолио.

| Урок | Тема | Практика |

# Курс 4. Фотографии с помощью нейросетей

**Длительность:** 4 недели · **Нагрузка:** 4–6 ч/неделя · **Пререквизит:** Курс 0
**Результат:** ученик создаёт и улучшает фотографии: портреты, предметку, рекламные и стоковые изображения, работает с ретушью, фонами и единым стилем.

## Что умеет выпускник
- Писать промпты для изображений: композиция, свет, объектив, стиль
- Редактировать существующие фото: заменить фон, дорисовать, убрать объект, ретушь
- Делать предметные съёмки и рекламные кадры без студии
- Готовить серии в едином стиле для соцсетей и бренда
- Апскейлить, восстанавливать старые фото, готовить к печати

## Неделя 1. Основа генерации изображений
**Цель:** уверенно получать нужную картинку.

| Урок | Тема | Практика |
|---|---|---|
| 1.1 | Классы генераторов и редакторов изображений; как выбрать | Сравнить 3 сервиса на одном запросе |
| 1.2 | Анатомия промпта для изображения: субъект, среда, свет, камера, стиль, качество | Разобрать 10 промптов |
| 1.3 | Язык фотографа: планы, ракурсы, фокусное расстояние, диафрагма, свет | Серия «один объект — 6 ракурсов» |
| 1.4 | Негативные ограничения, соотношение сторон, разрешение, seed, вариации | Управлять результатом |
| 1.5 | Композиция и цвет: правило третей, ведущие линии, палитра | Улучшить 5 кадров |

**ДЗ:** 10 качественных изображений по разным жанрам (портрет, пейзаж, еда, интерьер, предмет).

## Неделя 2. Редактирование и ретушь
**Цель:** работа с готовыми фото.

| Урок | Тема | Практика |
|---|---|---|
| 2.1 | Заменить фон, продолжить кадр, дорисовать (inpaint/outpaint) | Расширить кадр и заменить фон |
| 2.2 | Удаление объектов и дефектов, «чистка» кадра | Убрать 5 лишних элементов |
| 2.3 | Портретная ретушь: кожа, свет, цвет, естественность без «пластика» | Ретушь портрета |
| 2.4 | Реставрация старых фото и апскейл, цветокоррекция | Восстановить старое фото |
| 2.5 | Ручной финал: цветокор в фоторедакторе, кадрирование | Доработать результат |

**ДЗ:** 5 работ «до/после».

## Неделя 3. Коммерческая фотография
**Цель:** снимки под задачи бизнеса.

| Урок | Тема | Практика |
|---|---|---|
| 3.1 | Предметная съёмка: реальное фото + ИИ-сцена; удержание точности товара | Карточка товара |
| 3.2 | Рекламные баннеры и промо-визуалы | Баннер под кампанию |
| 3.3 | Соцсети: серия из 9 кадров в одном стиле | Сетка профиля |
| 3.4 | Фото для сайта и блога: стоки, иллюстрации, иконки | Набор для сайта |
| 3.5 | Единый стиль/бренд: референсы, свои стили и шаблоны промптов | Brand-style guide |
| 3.6 | Права и лицензии на ИИ-изображения; маркировка | Чек-лист |

**ДЗ:** пакет визуалов для выдуманного или реального бренда (10–15 кадров).

## Неделя 4. Свои модели и финальный проект
**Цель:** повторяемое качество и портфолио.

| Урок | Тема | Практика |
|---|---|---|
| 4.1 | Обучение/подключение «своего стиля» и объектов (LoRA, референсы) — в простом виде | Стиль на 15–20 своих фото |
| 4.2 | Автоматизация и «конвейер»: шаблоны, пакетная обработка | Конвейер для серии |
| 4.3 | Подготовка к печати и публикации: форматы, цветовые профили, размеры | Экспорт |
| 4.4 | Как продавать: услуги, стоки, шаблоны, печатная продукция; прайс | Оффер |
| 4.5 | Защита проектов | Презентация |

**Финальный проект:** фотопроект «под ключ» — 15–20 кадров в едином стиле + описание процесса.

### Критерии зачёта
- Единый стиль серии, отсутствие грубых артефактов
- Портреты выглядят естественно (руки, глаза, текст)
- Есть «до/после» и описание использованных приёмов
- Понимание прав на использование результатов

### Материалы
Библиотека промптов по жанрам, чек-лист «естественности» портрета, шаблоны сеток для соцсетей, таблица лицензий.

# Курс 5. Личные AI-аватары и цифровые персонажи

**Длительность:** 4 недели · **Нагрузка:** 5–6 ч/неделя · **Пререквизиты:** Курс 0, желательно Курс 4
**Результат:** ученик создаёт свой личный аватар (изображение, говорящий видеоаватар, голос) и/или бренд-персонажа, и умеет использовать их в контенте — безопасно и с согласием всех участников.

## Что умеет выпускник
- Создать стилизованные аватары для профиля и брендов
- Подготовить обучающую выборку из своих фото и обучить/подключить персональную модель
- Сделать говорящего видеоаватара и клонировать собственный голос (только свой или с письменного разрешения)
- Создать вымышленного бренд-персонажа с характером и историей
- Соблюдать этику и требования площадок, защитить свои данные

## Правила курса (важно)
- Работаем **только со своим лицом/голосом** или с письменного согласия человека
- Запрещены дипфейки реальных людей без согласия, обман, выдача ИИ-контента за реальный
- Ученик подписывает короткую памятку об этике до начала практики

## Неделя 1. Идентичность и стилизованные аватары
**Цель:** набор аватаров для профилей и бренда.

| Урок | Тема | Практика |
|---|---|---|
| 1.1 | Виды аватаров: статичные, анимированные, говорящие, 3D, персонажи | Выбрать формат под цель |
| 1.2 | Личный бренд: образ, стиль, цвета, характер, аудитория | Бриф образа |
| 1.3 | Стилизованные портреты: мультяшный, арт, кино, комикс, 3D | 10 вариантов из своего фото |
| 1.4 | Фон, одежда, эмоции: вариации аватара | Набор «эмоций» |
| 1.5 | Формат и размеры под платформы: соцсети, мессенджеры, сайты | Пакет иконок и обложек |

**ДЗ:** пакет аватаров (5 стилей × 3 эмоции) для личных профилей.

## Неделя 2. Персональная модель: «я в любом образе»
**Цель:** реалистичные и узнаваемые изображения себя.

| Урок | Тема | Практика |
|---|---|---|
| 2.1 | Как сервисы учатся на вашем лице: что происходит с данными и фотографиями | Проверить политику конфиденциальности сервиса |
| 2.2 | Сбор выборки: 15–30 фото, ракурсы, свет, что нельзя | Собрать датасет |
| 2.3 | Обучение персональной модели (простыми средствами) или использование референс-режима | Обучить/подключить модель |
| 2.4 | Промпты для «себя»: профессиональный портрет, путешествие, деловой образ, творческий образ | Серия из 20 кадров |
| 2.5 | Контроль сходства и естественности; исправление артефактов | Отбор и доработка лучших |
| 2.6 | Приватность и защита: водяные знаки, хранение датасета, удаление данных | Чек-лист безопасности |

**ДЗ:** 10 узнаваемых изображений себя в разных образах.

## Неделя 3. Голос и говорящий аватар
**Цель:** видеоаватар, который говорит вашим голосом.

| Урок | Тема | Практика |
|---|---|---|
| 3.1 | Синтез и клонирование голоса: запись образцов, качество, юридические рамки | Записать образцы, создать голос |
| 3.2 | Говорящая голова: фото → видео с речью, липсинк, мимика | Первое видео |

## Неделя 4. Бренд-персонаж, контент-система и проект
**Цель:** живой персонаж, который ведёт контент.

| Урок | Тема | Практика |

| 4.2 | Консистентность: референс-лист, единые промпты, повторяемость | 10 сцен с персонажем |

**Финальный проект (на выбор):**
1. Личный «цифровой двойник»: пакет изображений + говорящее видео + голос; или
2. Бренд-персонаж: карточка + 10 сцен + 2 ролика.

### Критерии зачёта
- Узнаваемость и естественность аватара
- Голос и мимика согласованы, нет грубых артефактов
- Собрано согласие для всех задействованных лиц/голосов
- Проект с маркировкой ИИ-контента там, где это требуется

### Материалы
Шаблон датасета, памятка по этике и согласию, «библия персонажа», шаблон контент-плана, чек-лист приватности.

# Производство курсов

## 1. Шаблон урока
Каждый урок содержит один и тот же набор:

1. **Цель** — одна фраза: «после урока ты сможешь…»
2. **Видео** 8–15 минут: хук (30 сек) → объяснение → показ на экране → итог
3. **Конспект** — ключевые шаги и промпты, которые можно скопировать
4. **Практика** — задание на 15–40 минут с чётким результатом
5. **Проверка** — как ученик поймёт, что всё получилось (чек-лист)
6. **Частые ошибки** — 3–5 пунктов

### Структура файлов на урок
```
course-XX/
  week-N/
    lesson-N.M/
      script.md        # сценарий
      slides/          # материалы к видео
      raw/             # исходная запись (в облаке, не в репозитории)
      final/           # финальный ролик (в облаке)
      notes.md         # конспект для учеников
      homework.md      # задание и критерии
```

## 2. Конвейер производства (на один урок)

| Шаг | Что делаем | Время |
|---|---|---|
| 1 | Сценарий и тезисы, проверка актуальности инструментов | 30–60 мин |
| 2 | Подготовка экрана: чистый рабочий стол, тестовые аккаунты | 15 мин |
| 3 | Запись (экран + голос, при необходимости камера) | 30–60 мин |
| 4 | Монтаж: нарезка, субтитры, звук, акценты | 45–90 мин |
| 5 | Конспект и ДЗ | 30 мин |
| 6 | QA и загрузка | 15 мин |

Ориентир: **один урок на 10 минут ≈ 3–4 часа работы целиком**. Курс из 25 уроков ≈ 100 часов, закладывать 2–4 недели с буфером.

## 3. Стек инструментов (классы, проверять актуальность)

| Задача | Класс инструмента |
|---|---|
| Запись экрана | Экранный рекордер с записью голоса |
| Монтаж | Настольный или облачный видеоредактор с авто-субтитрами |
| Звук | Микрофон USB/XLR, шумоподавление на ИИ |
| Хранение видео | Закрытый видеохостинг / облако |
| Материалы | Документы (Notion/Docs), GitHub для шаблонов |
| Бот и платежи | Telegram-бот + платёжный провайдер |
| ИИ для записи демо | Подписки на актуальные нейросети (текст, код, картинки, видео, голос) |
| Кураторская работа | Таблица ДЗ, шаблоны обратной связи |

## 4. Чек-лист перед записью модуля
- [ ] Проверить, что показываемые инструменты работают и не изменили интерфейс
- [ ] Проверить цены, лимиты, доступность в регионе учеников
- [ ] Подготовить запасной вариант для каждого платного сервиса (бесплатная альтернатива)
- [ ] Скрыть личные данные, ключи, уведомления
- [ ] Проверить права на музыку, шрифты, изображения в уроке

## 5. QA готового урока
- [ ] Звук чистый, нет провалов громкости
- [ ] Всё, что показано на экране, читаемо на телефоне
- [ ] Субтитры без ошибок
- [ ] Конспект совпадает с видео
- [ ] Практика выполнима за указанное время (проверил бета-тестер)
- [ ] Нет утёкших ключей/паролей в кадре

## 6. Обновление курсов
- Раз в 2 недели: обзор новостей в мире нейросетей (30 мин)
- Раз в месяц: «обновление» — короткие видео по изменившимся инструментам
- Раз в квартал: ревизия программы, замена устаревших модулей
- В каждом курсе — модуль «Что изменилось» в закреплённом канале

## 7. Работа куратора
- Ответ в чате в течение 24 часов (в будни)
- Проверка ДЗ: 48 часов, по шаблону — что хорошо, что улучшить, следующий шаг
- Еженедельный эфир: разбор типичных ошибок и лучших работ
- Мотивация: рейтинг «работы недели», напоминания в боте о дедлайнах
- Ученики, не заходящие 5 дней, получают личное сообщение

## 8. Обратная связь и улучшение
- Анкета после каждой недели (3 вопроса: понятно / сложно / чего не хватило)
- Опрос по завершении: NPS и отзыв
- Каждые 2 недели — правки по самым частым замечаниям

# Маркетинг и запуск

## 1. Воронка
```
Контент (Telegram, Reels/Shorts, YouTube) → Подписка на канал → Бесплатный продукт (мини-курс/чек-лист)
→ Прогрев (серия постов, кейсы, эфир) → Заявка/оплата в боте → Онбординг → Обучение → Апсейл следующего курса
```

## 2. Лид-магниты (бесплатные входные продукты)
- Мини-урок «Свой первый сайт за 30 минут» → ведёт в Курс 1
- Пак промптов для фото → Курс 4
- Шаблон «Как нарезать длинное видео за 10 минут» → Курс 2
- «Твой аватар за вечер» (пошаговый гайд) → Курс 5
- Чек-лист «10 ошибок новичка в вайбкодинге» → Курс 0

## 3. Публичный контент
| Рубрика | Формат | Частота |
|---|---|---|
| «Сделано нейросетью» — до/после, процесс | Reels/Shorts + пост | 3/нед |
| «Разбор инструмента» — 60 сек обзор | Видео | 2/нед |
| «Кейс ученика» | Пост + видео | 1/нед |
| «Промпт дня» | Пост | ежедневно |
| Прямой эфир «Собираем проект с нуля» | Эфир | 1/2 нед |

Правило: **каждый пост показывает результат**, а не рассуждает об ИИ.

## 4. План по неделям (для запуска Курса 0; шаблон для остальных)

### За 4 недели до старта
- Запуск публичного канала, 10–12 постов, вовлечение
- Интервью с аудиторией, сбор вопросов и возражений

### За 3 недели
- Лид-магнит + бот выдачи
- Первые тестовые рекламные закупки (микро-блогеры, каналы по теме)

### За 2 недели
- Открытие списка ожидания со скидкой раннего доступа
- Серия «кейсов» (бета-тестеры)

### За 1 неделю
- 2 бесплатных эфира: «Как работать с ИИ» и «Соберём мини-проект вживую»
- Ответы на возражения: «сложно», «не смогу», «устареет», «дорого»

### Неделя открытия (5–7 дней)
- День 1: открытие продаж, цена раннего доступа
- Дни 2–4: отзывы, разбор программы, ответы на вопросы
- День 5: дедлайн скидки, напоминания в боте
- День 6–7: закрытие набора, последний шанс

### После старта
- Приветствие и онбординг: карта курса, правила, знакомство в чате
- Первая победа в первые 48 часов (маленькое ДЗ)

## 5. Офферы и скидки
- Ранний доступ: −30% первые 5–7 дней
- Пакеты из нескольких курсов: −20–35%
- Скидка выпускника на следующий курс: −20%
- Партнёрка: 10–20% за приведённого ученика
- Гарантия: возврат в течение 7 дней, если пройдено ≤ 20% программы (условия в оферте)

## 6. Работа с возражениями
| Возражение | Ответ |
|---|---|
| «Я не умею программировать» | Курс начинается с нуля, кода вручную не пишем |
| «ИИ быстро меняется, курс устареет» | Обновления включены, обучаем принципам, а не кнопкам |
| «Бесплатно есть на YouTube» | Система, шаблоны, проверка ДЗ и результат к концу недели |
| «Нет времени» | 4–6 часов в неделю, уроки по 10 минут |
| «Дорого» | Рассрочка, пакеты, сравнение с ценой заказа сайта/ролика |

## 7. Метрики и отчёт (еженедельно)
- Охват, подписчики, стоимость подписчика
- Переходы в бота, заявки, оплаты, конверсии по шагам
- Доходимость курса, отзывы, возвраты
- Выручка, расходы, окупаемость (ROMI)
- Решение на неделю: что усиливаем, что отключаем

## 8. Каналы привлечения
1. **Органика:** Telegram-канал, Reels/Shorts, YouTube, комментинг в тематических сообществах
2. **Партнёрства:** блогеры и эксперты по ИИ/маркетингу, совместные эфиры

# Юридика, этика и риски

> Это рабочая памятка, не юридическая консультация. Оферту, политику конфиденциальности и договоры перед запуском проверить у юриста в вашей юрисдикции.

## 1. Документы перед запуском
- [ ] Публичная оферта на обучение
- [ ] Политика конфиденциальности и согласие на обработку персональных данных (бот собирает контакты и платежи)
- [ ] Политика возвратов
- [ ] Правила чата и памятка по этике (для курса «Аватары» — подписывается до практики)
- [ ] Регистрация деятельности (самозанятость/ИП/юрлицо) и учёт доходов
- [ ] Условия партнёрской программы

## 2. Авторские права и лицензии
- Проверять лицензии на шрифты, музыку, изображения, шаблоны, используемые в уроках
- Условия использования ИИ-сервисов: коммерческое использование результатов зависит от тарифа и правил сервиса — указывать в материалах и проверять перед записью
- Не показывать и не раздавать чужие платные шаблоны и курсы
- Материалы школы защищать: водяные знаки, персональные ссылки, условия в оферте

## 3. Этика работы с лицами и голосами
- Использовать только своё лицо/голос или с **письменного согласия**
- Запрет дипфейков реальных людей без согласия, обмана, клеветы, «голых» и компрометирующих изображений
- Маркировать ИИ-контент там, где этого требуют площадки и законы
- В курсах показывать, как **распознавать** подделки и защищать свои данные
- Несовершеннолетние: курсы 18+, либо только с согласия родителей и без работы с лицами

## 4. Данные учеников
- Не собирать лишнего; хранить минимум
- Домашние работы с личными фото хранить ограниченный срок, по запросу удалять
- Не публиковать работы учеников без согласия
- Секреты (ключи API, пароли) — никогда не в репозитории, не в кадре

## 5. Реестр рисков

| Риск | Вероятность | Влияние | Что делаем |
|---|---|---|---|
| Инструмент изменился/закрылся/стал платным | Высокая | Среднее | Учим принципам, даём аналоги, модуль «Что изменилось», обновления |
| Мало заявок на запуске | Средняя | Высокое | Тест спроса до записи, ранний доступ, партнёрства, доработка оффера |
| Ученики бросают курс | Высокая | Среднее | Маленькие победы, дедлайны, куратор, напоминания, короткие уроки |
| Перегруз куратора | Средняя | Среднее | Ограничить размер потока, помощник, шаблоны обратной связи |
| Нарушение авторских прав в уроках | Низкая | Высокое | Чек-лист лицензий, только свободные ассеты |
| Злоупотребление курсом «Аватары» | Низкая | Высокое | Памятка, согласие, модерация, отказ в доступе нарушителям |
| Технический сбой бота/доступа | Средняя | Среднее | Резервный способ выдачи вручную, мониторинг, тест перед запуском |
| Выгорание автора | Средняя | Высокое | Буфер 20%, поэтапный запуск, делегирование монтажа |
| Возвраты выше плана | Средняя | Среднее | Чёткие ожидания в оффере, первая победа за 48 часов |
| Утечка материалов | Средняя | Низкое | Персональные ссылки, водяные знаки, но не в ущерб UX |

## 6. Гигиена безопасности
- Двухфакторная аутентификация на всех сервисах и на Telegram
- Раздельные аккаунты для записи демо и личные
- Резервные копии материалов в двух местах
- Проверка ссылок и файлов, которые присылают ученики
